# 📊 Data Analytics Portfolio & Visitor Management System

A high-performance, luxury-themed personal data portfolio and real-time visitor logging web application. Built with a responsive frontend, custom visualization modal engines, and an asynchronous Python FastAPI backend connected to a cloud database.

---

## 🌟 Key Features

* **Interactive Analytics Showcase:** Detailed breakdowns of real-world data projects, including SQL window functions, exploratory data analysis (EDA), and DAX metrics.
* **Knowledge Repository:** Instant multi-format resource library allowing visitors to download complex `.SQL` scripts, Jupyter `.IPYNB` notebooks, Excel `.XLSX` financial models, and `.PDF` cheatsheets.
* **Real-Time Cloud Visitor Logging:** An automated visitor onboarding modal that captures visitor details and syncs directly to a cloud database.
* **Modern Luxury UI/UX:** Built with Tailwind CSS, custom HTML5 canvas animations, and full light/dark mode support.
